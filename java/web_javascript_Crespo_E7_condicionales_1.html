Ejercicio 07 — Introducción de datos y toma de decisiones

Este programa pregunta al usuario si quiere jugar. Si responde que sí, le pregunta por una fruta y muestra su precio usando un switch. Luego hace otra consulta para saber si desea continuar y termina con un mensaje adecuado. Si el usuario no quiere jugar o escribe una respuesta inválida, muestra un mensaje correspondiente.
