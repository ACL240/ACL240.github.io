Ejercicio 07 — Introducción de datos y toma de decisiones

Este programa pregunta al usuario si quiere jugar. Si responde que sí, le pregunta por una fruta. Si el jugador elige una fruta que no esté en la lista, da error. Muestra su precio usando un switch. Luego hace otra pregunta para saber si desea continuar. Si no, termina el programa. Si el usuario no quiere jugar o escribe una respuesta inválida, sale un mensaje de error.
